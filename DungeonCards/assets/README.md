# Графика: чем заменить шаблоны

Сейчас игра рисует **шаблоны** — цветные фигуры с буквами. Любой из них можно заменить картинкой:
положи файл с нужным именем в нужную папку внутри `assets/` — игра подхватит его **при следующем запуске**
(ничего перекомпилировать не нужно). Нет файла — рисуется шаблон, поэтому заменять можно по одной картинке.

## Формат

| Что | Рекомендация |
|---|---|
| Формат файла | **PNG**, 32 бита (RGBA, 8 бит на канал), цветовой профиль sRGB, **прозрачный фон** |
| Запасной формат | допустим `.jpg` с тем же именем (например `backgrounds/menu.jpg`); для спрайтов JPG не годится — нет прозрачности |
| Форма | **квадрат** для героев, врагов, боссов, предметов, плиток комнат и иконок. Не квадратная картинка вписывается по центру с сохранением пропорций |
| Размер | см. таблицы ниже. Игра рисует интерфейс в кадре 1280x720 и масштабирует под окно, поэтому берите **вдвое больше**, чем показано на экране: так картинка остаётся чёткой в окнах 1920x1080 и 2560x1440. Больше 256x256 для спрайтов не нужно |
| Поля | оставляй 5–10% прозрачного поля по краям |
| Направление | **герои смотрят вправо** (на врагов), **враги и боссы смотрят влево**. Автоматического отражения нет |
| Что НЕ рисовать на картинке | рамку уровня предмета, звёзды, полоски здоровья, имена и числа — игра рисует их сама поверх |
| Анимация | пока не поддерживается: один кадр на файл (рывок атакующего, вспышки и числа урона игра рисует сама) |
| Шрифт | `assets/font.ttf` — любой TTF с кириллицей; иначе берётся шрифт Windows |

## Модельки

Игра двухмерная, **3D-модели напрямую не поддерживаются**. Если у вас есть 3D-модели, сделайте с них
**рендеры в PNG с прозрачным фоном**: одна камера, один ракурс для всех (герои — вид «в профиль, лицом вправо»,
враги — лицом влево), квадратный кадр 256x256 для боссов и 128x128 для остальных.
Для pixel-art берите кратные размеры (64x64 или 128x128), увеличение идёт с плавным сглаживанием.

## Куда класть файлы

Игра ищет папку `assets/` в рабочей папке, затем на уровень и два уровня выше. Скрипт сборки копирует `assets/` рядом
с `DungeonCards.exe` после **каждой** сборки, поэтому правьте картинки в `assets/` проекта (или кладите их прямо рядом
с exe). Чтобы убедиться, что имена файлов верны, запустите `list_assets` — он печатает полный перечень.

Опечатка в имени не приведёт к ошибке: игра просто продолжит рисовать шаблон.
